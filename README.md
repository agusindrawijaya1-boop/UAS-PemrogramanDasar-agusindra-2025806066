## 📌 Deskripsi Aplikasi
Aplikasi ini merupakan sistem manajemen inventaris gadget berbasis web yang digunakan untuk mengelola data perangkat seperti smartphone dan laptop.  
Pengguna dapat melakukan operasi CRUD (Create, Read, Update, Delete) terhadap data gadget melalui REST API dan tampilan web sederhana.

---

## 🚀 Teknologi yang Digunakan

- CSS3
- JavaScript (Fetch API)
- Node.js
- Express.js
- MySQL
- REST API
